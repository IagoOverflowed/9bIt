# The 9b9t it price charts
This is a project to provide an north for trades in the 9b9t it server

# How it works:

 - This project is composed of various "charts" 
 - Each chart stablishes a pricing reference and a bunch of equivalencies
 - To be tracked an item MUST be on at least 1 chart
 - Problems in the charts may be adressed via github issues or directly via pull-reqs
 - If you don't find any satisfactory chart to price any item you MAY propose the addition of a new chart
 - DO use past trades as references for pricing proposals
 - For mass-minted shulkers with various different items (known as kits), enchanted items and other special items, they will be described and assigned an ID in the items folder under the apropriate file (for organizing purposes)
 - This project will start with a base chart with a firework shulker as a reference.
 - You're NOT obliged to follow these charts when doing a trade, however, people will apreciate if you do
 - The charts MAY be moved out of github if people wish so
 - All changes **MUST** be pushed to working branch, so people can discuss them before they become active
 - **IF YOU THINK THIS IS RETARDED, HELP IT BE LESS SO BE CONTRIBUTING TO IT!**
